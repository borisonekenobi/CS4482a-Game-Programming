# 2D Adventure Game

This project is a simple Unity 2D top-down game. The goal is to move around the level, avoid hazards, fix enemies with projectiles, and keep your health up.

## Controls

- Movement: Arrow Keys
- Shoot Projectile: `C`
- Special Ability: `X`

## Main game logic files

- `Assets/_2DAdventureGame/Scripts/PlayerController.cs`
- `Assets/_2DAdventureGame/Scripts/EnemyController.cs`
- `Assets/_2DAdventureGame/Scripts/Projectile.cs`
- `Assets/_2DAdventureGame/Scripts/DamageZone.cs`
- `Assets/_2DAdventureGame/Scripts/HealthCollectible.cs`
